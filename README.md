# 陪伴 · 计划

> 一个帮你在**碎片时间**里推进多目标、并在**提前完成后**告诉你"多出来的时间该干嘛"的极简陪伴式计划应用。

## 它解决什么问题

在职学习者 / 学生最常见的处境：要在主业（上课 / 上班）之外，同时推进好几条线——考试、竞赛、技能、健康。时间被切成碎片，还要面对一个尴尬的问题：

**计划做完了，多出 30 分钟，干嘛？**

普通待办 / 番茄钟只帮你"把事做完"，到这里就停了。这个应用多做一步：根据剩余时长 + 你的精力 / 环境 + 各目标的截止日期和习惯缺口，**主动推荐**你用多出的时间做点什么，并附一句理由。

## 核心功能

1. **今日计划 + 打卡**——把空闲碎片排上任务，做完打勾，实时看"可支配时长 / 完成进度"。
2. **固定作息反推碎片**——填好每天固定的"没空时间"（上课 / 吃饭 / 睡觉），应用自动算出你的空闲碎片，不用一个个手填。
3. **事项池（愿望池）**——把想做的事存进去，每个带标签：最短时长 / 精力 / 场景 / 优先级 / 截止或习惯。
4. **空余时间建议**——规则引擎按「时长够不够 → 环境精力匹配 → 优先级排序」出前 3 条，每条带一句理由（如"距黑客松还剩 14 天""你已经 3 天没跑步了"）。

## 怎么运行

纯前端、零依赖，**直接双击 `index.html` 用浏览器打开即可**（手机浏览器也一样）。数据存在浏览器本地 `localStorage`，刷新不丢、不上传。

> 也可以用任意静态服务器（如 `python -m http.server`）在 `localhost` 跑，效果相同。

## 技术选型

- 原生 HTML / CSS / JavaScript，单文件 `index.html`
- 无框架、无构建、无后端
- 数据持久化：`localStorage`
- 建议引擎：纯规则（可配置优先级、截止日期、习惯间隔），无外部 API 调用、可离线

## 数据与隐私

所有数据只存在你自己的浏览器里，不经过任何服务器。多用户 / 云同步是未来的扩展方向，当前刻意不做登录。

## 未来方向

- 半自动排程（根据碎片时间自动建议怎么排，人确认后生效）
- 建议引擎升级为「规则 + LLM」，给出更自然、更聪明的建议
- 多用户 + 云端同步（账号体系、数据隔离）
- PWA（主屏图标、离线可用、桌面/移动端推送提醒）

## 设计思路（一句话）

数据分两层：**今日计划**（当天要做）和**事项池**（长期想做的所有事）。"盈余建议"从事项池里挑，而不是从今日计划里挑——这是它和普通待办最本质的区别。
