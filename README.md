# 陪伴 · 计划

> 一个帮你在**碎片时间**里推进多目标、并在**提前完成后**告诉你"多出来的时间该干嘛"的极简陪伴式计划应用。

## 它解决什么问题

在职学习者 / 学生最常见的处境：要在主业（上课 / 上班）之外，同时推进好几条线——考试、竞赛、技能、健康。时间被切成碎片，还要面对一个尴尬的问题：

**计划做完了，多出 30 分钟，干嘛？**

普通待办 / 番茄钟只帮你"把事做完"，到这里就停了。这个应用多做一步：根据剩余时长 + 你的精力 / 环境 + 各目标的截止日期和习惯缺口，**主动推荐**你用多出的时间做点什么，并附一句理由。

## 核心功能

1. **今日计划 + 打卡**——把空闲碎片排上任务，做完打勾，实时看"可支配时长 / 完成进度"。
2. **固定作息反推碎片**——填好每天固定的"没空时间"（上课 / 吃饭 / 睡觉），应用自动算出你的空闲碎片，不用一个个手填。
3. **事项池（愿望池）**——把想做的事存进去，每个带标签：最短时长 / 精力 / 场景 / 优先级 / 截止或习惯。
4. **空余时间建议**——规则引擎按「时长够不够 → 环境精力匹配 → 优先级排序」出前 3 条，每条带一句理由（如"距黑客松还剩 14 天""你已经 3 天没跑步了"）。
5. **冲刺计划（考前 11 天备考）**——「冲刺」页签内置一份 11 天备考配额（2026年10月考期：马原 / 公司法 / 近代史 / 英语二，共 420+ 学习单元）：按科目分组展示当天考点（高频 / 星级 / 一句话要点 / 单词组），勾掉即计入进度；**当天没勾完的自动顺延**到以后每一天，低星考点可一键让位；考前自动切到"考试日冲刺视图"（当天科目高频扫读 + 倒计时），考试安排可在页内直接修改。

## 冲刺计划的数据来源与再生成

- `plan-data.js` 是内置的只读计划数据（由 `build_plan_data.py` 从「自考本复习」文件夹的密训/急救/真题文本提取生成），仅本地使用。
- 想重新生成：工作区根目录跑 `python build_plan_data.py`（依赖 `_提取文本/` 下已提取的文本与 `extract_pdf.py` / `extract_batch.py` 提取管线）。
- **考点要点是完整正文，不再截断**：早先版本用 `shorten()` 把要点砍到 48~60 字，出现"（物质是本原、机械运动）、辩"这种半句，没法复习；现已改为拼接整块正文（PDF 折行按右边距自动续接，独立要点用「；」分隔，丢失的列表序号补成 ①②③）。列表里默认折 3 行，长要点给「展开全文 ↓」，右上角可「全部展开」。
- **提取端修复**：`extract_pdf.py` 对没有 ToUnicode 表的西文简单字体（Times New Roman / Calibri）改为按 WinAnsi 码位回退——马原几本 PDF 的数字原先全丢（"（世纪年代中期）"），现在恢复成"（19世纪40年代中期）"；`build_plan_data.py` 另修了页码漏进正文、跨行标题被当正文、正文子序号被当新条目等问题。
- 勾选 / 让位 / 考试安排覆盖都存在 `localStorage` 的 `companion-sprint-v1` 键里，与事项池互不干扰；条目 id 含序号，重新生成数据后若有对不上的勾选，手动取消即可。

## 怎么运行

纯前端、零依赖，**直接双击 `index.html` 用浏览器打开即可**（手机浏览器也一样）。数据存在浏览器本地 `localStorage`，刷新不丢、不上传。

> 也可以用任意静态服务器（如 `python -m http.server`）在 `localhost` 跑，效果相同。

## 技术选型

- 原生 HTML / CSS / JavaScript，单文件 `index.html`
- 无框架、无构建、无后端
- 数据持久化：`localStorage`
- 建议引擎：纯规则（可配置优先级、截止日期、习惯间隔），无外部 API 调用、可离线

## 自动化验收（tests/）

`tests/` 里是这套逻辑的验收台，用 Node 直接执行 `app.js`（伪 DOM / 冻结时钟，因此断言可复现），不需要浏览器、不修改项目文件：

| 脚本 | 覆盖 | 当前结果 |
|---|---|---|
| `verify-suggest.mjs` | 空余时间建议：完成/已排不再推荐、时长账、强制上报耗时、让出的时段能排回去 | 87/87 通过 |
| `verify-checkin-flow.mjs` | 打卡链路：点勾 → 弹窗 → 填耗时 → 提交（能查监听器/属性名这类接线问题） | 32/32 通过 |
| `verify-import-repeat.mjs` | 一键导入 = 增量补新；新建习惯当天可见但不自动进今日计划 | 21/21 通过 |
| `verify-demo-state.mjs` | `演示数据-一键填充.js` 能产出可录制状态（早 6 点 / 下午 3 点两种） | 全部通过 |
| `verify-sprint.mjs` | 冲刺计划：每日配额渲染、勾选持久化、顺延、低星让位、考试日扫读视图、展开全文/全部展开 | 47/47 通过 |
| `verify-plan-data.mjs` | 冲刺数据完整性：每个考点都有完整正文、"马原第3条"等曾经的半句已补全、数字与页码噪声没混进要点 | 21/21 通过 |
| `repro-suggest-bug.mjs` | 复现"完成后仍推荐已完成事项"这个历史 bug | 已修复（exit 0） |
| `verify-browser.mjs` | 真浏览器验收：起静态服务 + headless Chrome，真点「一键导入」并截图 | 需在普通终端跑（会连 Chrome 调试端口） |

跑法（在 `tests/` 目录下）：

```bash
node verify-suggest.mjs
node verify-checkin-flow.mjs
node verify-import-repeat.mjs
node verify-demo-state.mjs
node verify-sprint.mjs
node verify-plan-data.mjs
node verify-browser.mjs      # 需要本机 Chrome
```

> 这些脚本原先散在工作区根目录、自称"临时验收台（跑完可删）"；现已收进仓库以免丢失。它们用相对路径读 `../app.js`，**移动位置时要同步改路径**。

## 数据与隐私

所有数据只存在你自己的浏览器里，不经过任何服务器。多用户 / 云同步是未来的扩展方向，当前刻意不做登录。

## 未来方向

- 半自动排程（根据碎片时间自动建议怎么排，人确认后生效）
- 建议引擎升级为「规则 + LLM」，给出更自然、更聪明的建议
- 多用户 + 云端同步（账号体系、数据隔离）
- PWA（主屏图标、离线可用、桌面/移动端推送提醒）

## 设计思路（一句话）

数据分两层：**今日计划**（当天要做）和**事项池**（长期想做的所有事）。"盈余建议"从事项池里挑，而不是从今日计划里挑——这是它和普通待办最本质的区别。
